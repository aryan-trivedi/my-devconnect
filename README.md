# DevConnector 🚀

A full-featured **MERN stack** social network app for developers to connect, share posts, and showcase their experience and skills.

---

## ✨ Features

- User registration and authentication (JWT)
- Create and update developer profiles
- Add experience and education details
- Browse other developers’ profiles
- Create, like, comment, and delete posts
- GitHub integration to show latest repos
- Protected routes and error handling
- Token expiry handling with auto-logout

---

## 🛠 Tech Stack

**Frontend**
- React (with Hooks)
- Redux Toolkit for state management
- Axios for API communication
- React Router v6

**Backend**
- Node.js + Express
- MongoDB with Mongoose
- JWT for authentication
- Express Validator
- Axios (server-side GitHub API requests)
